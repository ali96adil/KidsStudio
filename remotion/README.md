# Remotion color-card experiment

Optional standalone ten-second 1280×720 / 30fps educational template.

Requires Node.js and local installation of packages; not connected to the production coordinator.

```bash
cd remotion
npm install
npm run render
```

No narration is generated or attached. No child image or identity assets are included.
This is a smoke-test template only, not an approved episode.
Check the installed Remotion version, fonts, codec and output visually before integration.
Do not commit `node_modules` or `out`.
